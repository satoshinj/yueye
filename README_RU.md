## ✨ Ключевые возможности

| Модуль | Возможности | Преимущества |
|---|---|---|
| **Умный выбор маршрута** | Статья / Онлайн-ридер / Полный снимок экрана | Текстовые статьи сохраняются в **PDF с поиском** (на 90% меньше по размеру); Canvas сохраняет исходные пиксели |
| **Сверхбыстрая работа** | `canvas.toDataURL` + проверка стабильности по хешу | **26 мс/страница** (в 8 раз быстрее стандартных скриншотов), экспорт 100 страниц за секунды |
| **Динамический подбор перелистывания** | Поле ввода → Кнопка «Далее» → Прокрутка → Клавиатура | **Без жестко заданных селекторов**; программа сама находит и фиксирует рабочий способ пагинации |
| **Устойчивость и мгновенная остановка** | Предзагрузка + экспоненциальный повтор + быстрая остановка | Автоматическое закрытие всплывающих баннеров; кнопка «Стоп» прерывает работу за миллисекунды |
| **Широкая поддержка браузеров** | Автопоиск Edge, Chrome, 360, QQ Browser, Brave, Cent | Очистка зависших блокировок (`SingletonLock`), скрытие панели автоматизации, работа через корпоративные прокси |
| **Мультиформатность и диапазон страниц** | PDF (текст/изображения) / Word / Markdown / Текст / Картинки | Поддержка диапазона страниц (например, `1-10`); фоновый асинхронный экспорт без зависания интерфейса |

## 🚀 Быстрый старт

### Вариант A: Портативная версия (Рекомендуется · Без установки Python)

1. Скачайте `Yueye-v1.0.3-win-x64.zip` со страницы [GitHub Releases](https://github.com/satoshinj/yueye/releases) и распакуйте архив.
2. Запустите `阅页.exe`:
   - Нажмите **「登录浏览器」(Войти в браузер)** для авторизации в вашей учетной записи.
   - Вставьте URL документа, выберите формат и диапазон страниц, затем нажмите **「开始抓取」(Начать)**.

### Вариант B: Командная строка CLI (Автоматизация и пакетная обработка)

```cmd
# Экспорт всего документа в PDF
阅页.exe --url "https://..." --format pdf

# Экспорт страниц с 1 по 10 в формате Markdown в указанную папку
阅页.exe --url "https://..." --format markdown --range 1-10 --out ./output

# Указание пути к пользовательскому браузеру
阅页.exe --url "https://..." --browser "C:\Path\To\Chrome.exe"
```
